Technical Implementation Notes

Tailwind Utility First

Always use semantic tokens (e.g., bg-surface-container) instead of arbitrary hex codes to ensure Dark/Light mode theme switching works automatically via the .dark class on the html tag.

Iconography

System uses Material Symbols Outlined. Use the standard transcription rules for data-icon strings. Standard weight is 400. For active states, use 'FILL' 1 variation settings.

Component Naming

Standard PascalCase for components. Shared components (SideNavBar, TopAppBar) are defined in the global JSON and should be treated as immutable structural anchors for all dashboard sub-views.
